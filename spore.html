Get a domain ($1.50 for most .lol domains for the first year, about $13 for .net) at porkbun.com and a minimal "droplet" virtual Ubuntu server at digitalocean.com for $5/month. Point the name servers at porkbun to NS1.DIGITALOCEAN.COM, NS2.DIGITALOCEAN.COM, NS3.DIGITALOCEAN.COM. In Digital Ocean web interface, create a domain, put in your new domain. Then add A records for @ and www that point to that droplet. Then log into your droplet with ssh and replicate the spore as follows:

sudo apt update 
sudo apt install apache2 -y
sudo apt install php libapache2-mod-php -y
mkdir -p /var/www/[DOMAIN]/public_html
chown -R www-data:www-data /var/www/[DOMAIN]/public_html
cd /var/www/[DOMAIN]/public_html
sudo curl -o spore.php https://metaspore.net/spore.php
php spore.php
cd /etc/apache2/sites-available/
sudo curl -o template.conf https://metaspore.net/template.conf.txt
cp template.conf [DOMAIN].conf
sed -i "s/TEMPLATE_DOMAIN/[DOMAIN]/g" [DOMAIN].conf
a2ensite [DOMAIN].conf
systemctl restart apache2
certbot --apache -d [DOMAIN]
