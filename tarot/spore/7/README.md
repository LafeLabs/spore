## [save-file.php](https://github.com/LafeLabs/spore/blob/main/save-file.php) CODE:

```
    $data = $_POST["data"]; 
    $filename = $_POST["filename"];
    $file = fopen($filename,"w");
    fwrite($file,$data); 
    fclose($file);
```
